# どうぶつお絵かきで学ぶ Git と GitHub

中学生向けのインタラクティブなデモです。クマさんが公開している絵に、好きな動物を描き足して取りこんでもらうまでの流れを、ブラウザ上で体験できます。

フォーク → クローン → ブランチ → コミット → プッシュ → プルリクエスト → レビュー → マージ → 同期・プル

デモ: https://yandod.github.io/git-oekaki/

- `index.html` 1ファイルで動きます（外部への通信なし）
- 操作ごとに、対応する本物の git コマンドを表示します
- 日本語 / English / 한국어 に対応（ヘッダで切り替え。URL末尾に `#en` `#ko` を付けると、その言語で開きます）
